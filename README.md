# Miles The Barber

Static site ready for GitHub Pages.

## Deploy
1. Upload these files to the repository root.
2. In GitHub: **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your branch (typically `main`) and folder `/ (root)`.
5. Save.

All booking CTAs link to Miles The Barber's existing Booksy profile.
